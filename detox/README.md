# 💧 Detox Monitor: мониторинг цен на Aqua Миргород Detox

Отдельная платформа, не связанная с Пивомером. Каждый день собирает цены на воду
Aqua Миргород Detox в сетях и интернет-магазинах по всей Украине и сравнивает их
с ценами на сайте бренда. Видно, кто продаёт дешевле сайта. Бесплатно, без ИИ и без сервера.

Адрес после публикации: `https://<логин>.github.io/<репозиторий>/detox/`

## Что показывает

- **Обзор по объёмам** (0,33 / 0,5 / 1 / 1,2 / 1,5 л): цена на сайте бренда, минимум,
  средняя и максимум на рынке, где дешевле всего, цена за литр, сколько продавцов дешевле сайта.
- **Все предложения**: сеть, город и адрес магазина, цена, скидка и срок её действия,
  разница с сайтом в гривнах и процентах, наличие, ссылка на товар.
  - Фильтры по объёму, городу и сети, «только дешевле сайта», «только в наличии».
  - Сортировка по любой колонке.
  - Кнопка **«Скачать CSV»** выгружает таблицу для Excel.
- **Минимальная цена по сетям**: таблица «сеть × объём», дешевле сайта выделено красным.
- **Динамика цен**: минимум, средняя и цена сайта по дням.
- **Источники данных** и их статус.
- Три языка (UA / RU / EN), работает на телефоне и компьютере, есть офлайн-режим.

## Откуда данные

| Источник | Что берётся | Статус |
|---|---|---|
| zakaz.ua | все магазины всех сетей во всех городах: NOVUS, Ашан, Епіцентр, MEGAMARKET, Таврія В, ЕкоМаркет и другие | ✅ автоматически |
| АТБ (atbmarket.com) | цена на сайте (общая онлайн-цена) | ✅ автоматически |
| Сайт бренда | эталонные цены | XML-фид или вручную, см. ниже |
| Сільпо, Rozetka, Fozzy, tabletki.ua | — | закрыты защитой от роботов (Cloudflare) |
| Varus | — | цены только через внутренний API |

Защиту сайтов от роботов платформа намеренно не обходит.

## Эталонные цены сайта бренда

Задаются в файле `detox/config.json`. Его можно отредактировать прямо на GitHub
(иконка карандаша) и сохранить, сайт обновится сам.

**Вариант 1: XML-фид (лучше всего, цены обновляются сами).** В админке Horoshop создайте
фид товаров для Google Merchant, Prom или Rozetka (раздел маркетинга / экспорта) и вставьте
ссылку на него:

```json
"feedUrl": "https://shop.aquamyrgorod.com.ua/....xml"
```

Из фида берутся все товары, в названии которых есть Detox. Объём определяется по названию.

**Вариант 2: вручную.** Цена в гривнах для каждого объёма в миллилитрах:

```json
"basePrices": { "330": 39.9, "500": 54.9, "1000": 74.9, "1500": 99.9 }
```

Если заданы оба варианта, цены из фида важнее ручных.

## Как устроено

```
detox/                      — приложение (HTML + JS, без сборки)
  config.json               — настройки: ссылка на сайт, фид, ручные цены
scripts/fetch-detox.mjs     — сборщик цен → data/detox.json, data/detox-history.json
.github/workflows/deploy.yml — запускает сборщик каждое утро и публикует сайт
```

Запуск на компьютере:

```bash
node scripts/fetch-detox.mjs      # Node 18+, около минуты
python3 -m http.server 8000       # откройте http://localhost:8000/detox/
```
