# 🍺 Пивомер — цены на пиво в Украине

Приложение для телефона (PWA): сканируете штрихкод или фотографируете этикетку и
узнаёте, что это за пиво и где оно дешевле в Украине. Полностью бесплатно: без
сервера, без ИИ и без платных API.

## Что умеет

- **Сканер штрихкода** с камеры. На Android работает встроенный детектор, на iPhone — ZXing.
  Цифры можно ввести и вручную.
- **Фото этикетки.** Текст распознаётся прямо на телефоне (Tesseract.js, украинский и
  английский), затем находится похожее пиво в базе.
- **Поиск по названию** на кириллице и латинице: «хайнекен» найдёт Heineken.
- **Цены в 20 сетях**: NOVUS, METRO, Ашан, Епіцентр, MEGAMARKET, Таврія В, WineTime и
  другие. Минимальная и средняя цена, цена за литр, скидки и срок их действия, ссылка на
  товар в магазине.
- **Динамика цены**: история минимальной цены за последние 180 дней.
- **Подборки**: скидки, дешевле за литр, крепкое, безалкогольное; фильтр по стране.
- **Мировая база**: если штрихкода нет в магазинах, описание берётся из
  [Open Food Facts](https://world.openfoodfacts.org).
- Работает **офлайн** с последними загруженными ценами. Можно добавить на главный экран.

## Откуда данные

| Что | Источник | Как часто |
|---|---|---|
| Цены, наличие, скидки, состав | интернет-магазины сетей на zakaz.ua (Киев) | раз в день |
| Описание по штрихкоду | Open Food Facts | при открытии карточки |

Цены интернет-магазинов, в обычных магазинах и других городах они могут немного отличаться.

## Как это устроено

```
index.html, css/, js/          — само приложение (без сборки, чистый JS)
  js/search.js                 — нечёткий поиск (транслит + триграммы)
  js/scanner.js                — камера и штрихкоды
  js/ocr.js                    — распознавание этикетки
  js/off.js                    — Open Food Facts
sw.js, manifest.webmanifest    — офлайн-режим и установка на телефон
vendor/                        — ZXing и Tesseract.js (с языками ukr+eng)
scripts/fetch-prices.mjs       — сборщик цен → data/beers.json, data/history.json
.github/workflows/deploy.yml   — каждый день собирает цены и публикует сайт
```

Сервера нет. GitHub Actions каждое утро запускает сборщик цен и выкладывает приложение
вместе со свежими данными на GitHub Pages.

## Как опубликовать

1. Бесплатный GitHub Pages работает только для **публичных** репозиториев:
   Settings → General → Danger Zone → Change visibility → Public. В репозитории нет
   ключей и личных данных.
2. Settings → Pages → Source: **GitHub Actions**.
3. Влейте изменения в `main` или запустите вручную: Actions → «Обновить цены и опубликовать» → Run workflow.
4. Приложение появится по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.
   Откройте его на телефоне и добавьте на главный экран.

> GitHub отключает ежедневный запуск, если в репозитории 60 дней не было изменений.
> Тогда зайдите в Actions и включите его снова.

## Запуск на компьютере

```bash
node scripts/fetch-prices.mjs     # Node 18+, соберёт data/beers.json (~1 мин)
python3 -m http.server 8000       # откройте http://localhost:8000
```

Камера в браузере работает только по `https://` или на `localhost`.
